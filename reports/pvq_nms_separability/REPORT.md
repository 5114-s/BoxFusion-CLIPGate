# PVQ-AR@NMS 可分性测试 + 桶交集检查（CLIP ViT-H-14）

核验日期：2026-09-03（Asia/Shanghai）

## 结论

1. **CLIP 外观信号存在且强**：同一物体合并对的相似度中位数 **0.9685**，错吞对（不同物体）
   **0.8891**，**AUC = 0.8385**——可分性门槛（信号存在）通过。
2. **但朴素全局阈值不可用**：操作曲线显示高恢复率代价陡峭——
3. **桶交集极小**：84 个被吞 GT 中仅 6 个已被 WeDetect birth 覆盖，
   **78 个仍待仲裁挽回**——流①与流②（+3.03 已落地）几乎不相交，叠加期望成立。

## 独立复算（对照另一会话审计）

18,272 次合并：correct_dedup 5,843 / clutter 11,845 / wrong_swallow 584 /
absorbed-TP 243 事件 → **84 唯一 GT**（对方报 247→88；匹配细节差异，结论一致）。

## 操作曲线（单视角 crop-vs-crop 相似度，全局阈值）

| 恢复 absorbed | 分裂阈值 | 打破正确合并 |
|---|---|---|
| 50% | 0.889 | 6.4%（采样 420 中 27） |
| 70% | 0.932 | 14.5% |
| 80% | 0.949 | 26.9% |
| 90% | 0.965 | 46.4% |

按 5,843 次正确合并全量缩放：50% 点 ≈ 375 个重复 FP（原生分数中段）vs 换回
~39 个 GT——**朴素全局阈值大概率为 AP 净负**，不能直接上线。

## 对 active 设计的约束（由本测试导出）

1. **精度优先操作区**：sim < 0.83 约换回 25% absorbed（~20 GT，+1.4 recall）
   仅 ~2% 破裂——active 版应从这里起步再逐步放宽；
2. **必须门控**：只在外观低相似 **且** 几何不确定（合并 IoU 贴阈值带）时干预——
   双条件交集能把 FP 成本压到远低于全量缩放值；
3. **多视角原型优于单 crop**：本测试是单视角单 crop 的下界；PVQ 的视角条件
   原型记忆（跨视角平均）应显著改善分离度——这正是 active 实现该用的机制；
4. **WeDetect embedding 升级有具体靶子**：把 absorbed 分布压低 / correct 分布抬高，
   在精度优先区把可换回比例从 25% 往上推。

## 方法

- 事件：`diagnostics/pvq_nms_observer_score05/`（另一会话的 NMS observer full100）。
- GT 标注：评测器同款变换链 + AABB IoU ≥0.15；missed 判定用 Cbest 贪心覆盖。
- 对照类：correct_dedup 均匀采样 420（seed=0）。
- 特征：管线同款 open_clip ViT-H-14（`models/open_clip_pytorch_model.bin`），
  事件关键帧投影 crop（15% 边距），992/1012 成功嵌入（20 帧缺失跳过）。
- 产物：`/tmp/nms_event_labels.jsonl`（584 错吞 + 420 对照，含几何）、
  `/tmp/nms_clip_separability.json`（逐事件相似度）。

## 追加（同日）：全量成本模型与 active 判定

**朴素门控 active 判死。** 四类全量缩放（absorbed 243 / wrong_non_absorbed 341 /
correct_dedup 5,843 / clutter 11,845）下的 FP:TP 交换率：

| 判别信号 | 最佳 FP/TP | 说明 |
|---|---|---|
| CLIP 单 crop | 14–22× | AUC 0.84 但基础率悬殊 |
| **WeDetect 嵌入** | **6–7×** | 质变信号：同物体合并的 child/parent 匹配**同一 proposal**，相似度恒 1.0（离散判别）；错吞中位 0.655 |
| WeDetect+CLIP+IoU 组合 | 10–16× | 无改善——FP 大头是 clutter（74%），三票都拦不住杂物 |

结论：任何"分裂合并"动作在 18,029 个不该碰的事件上制造 6× 以上的重复/杂物 FP，
active full100 不予执行（省 2 小时确认已知结论）。

## 正确机制（由成本模型导出）：被吞 child 回收 birth

分裂不是唯一动作。observer 日志里每个被吞 child 都有几何；同一物体跨关键帧
反复被吞，留下多视角轨迹。把全部被吞 child 送入流②已有的因果确认机器：

- **native 去重自动杀掉 correct_dedup 的重复**（child-vs-parent IoU 中位 0.64 ≥ 0.10 门槛）；
- **≥3 帧确认漏斗压制 clutter**（流②实测 47k 候选 → 593 birth 的 79× 漏斗）；
- 词表门可进一步清理；输出走低分追加（已证安全）。

限制：absorbed 事件/GT ≈ 2.9，3 帧确认只能兑现一部分；预期回收 40–50 GT
（+2.8~3.5 recall 点），且全程离线、复用当日全部代码。
