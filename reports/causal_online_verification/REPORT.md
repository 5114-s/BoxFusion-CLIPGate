## 机制级发现（本次最重要的科学结论）
离线版唯一实质的未来信息 = **对最终地图去重**。它值 1.7 AP15，机制：
1. map-so-far 全是瞬态框（例：scene0011_01 全程 234 个 init_id，最终活跃 31）——对它去重会掐死漏斗（v3：births 533）；
2. 出生级严格去重（v2）恰恰杀掉与 native 重叠 0.25–0.5 的 birth——而那正是 NMS 吞并恢复的目标框（native 把两个 GT 并成一框时，birth 恢复第二个）。
即：**吞并恢复本质上需要"允许与 native 中度重叠"的因果去重规则**。方向：稳定性门控去重（仅对已存活≥N关键帧的地图框去重）——因果且预测存活性，M4 自校准的直接素材。

## Addendum: 因果差距恢复尝试（六连负，2026-09-04 深夜）

| 变体 | 思路 | births | AP15/25/50 |
|---|---|---|---|
| v2（冠军） | receipt 不设防 + 场景末对最终 native 去重 | 928 | **41.28/37.05/18.22** |

| v7 | 不杀候选，但重叠提案禁入已有 receipt（防污染）| 564 | 39.76/35.59/17.62 |

**结论：不可恢复（在现有信息源内）。** 机制定论：候选（被吞/漏检物体）到达的时刻，native 地图在 同一位置 真的有框——这正是该物体被漏的原因；对未沉淀的地图做任何形式的提案级去重（存活门/收缩补偿/污染隔离）都会掐断恢复流。离线版的 1.67 来自"哪些框最终沉淀在哪"这一不可化简的未来信息。

**论文口径**：双数字报告——在线因果 41.28（系统保证）+ 离线后处理上界 42.95（含场景末非因果去重），差距 −1.67（兑现率 96%），并有六变体负结果表证明差距是信息受限而非实现受限。这本身是本线工作没人报过的"因果性价格"测量。

若未来继续：唯一有原理的剩余杠杆 = 用地图框自身的年龄轨迹预测最终几何/存留（尺寸成熟模型）——属 M4 自校准范畴，六个局部修复失败已压低先验。

## Addendum 2: 之前"不可恢复"的结论是错的——v8/v9 修正（2026-09-04 深夜²）

用户追问触发重审。发现前一 Addendum 的诊断错误：**离线算法（提案级去重 vs 最终地图）本身就是场景末后处理，其全部输入在场景末均为过去数据——它在标准在线语义下本来就是因果的**。v1–v8 掉分不是"因果代价"，而是我在更严的"每关键帧定稿"语义下改了算法（v2 的逐出生过滤 vs 离线的逐观测过滤），属于语义漂移。

| 变体 | 语义 | births | AP15/25/50 |
|---|---|---|---|
| 离线（sealed native + 旧事件源） | 提案级去重 vs 最终地图 | 1,156 | 42.95/38.87/19.33 |
| v8 | receipt 内逐观测过滤（场景末） | 971 | 41.14/37.05/18.43 |
| **v9 = 离线算法逐字复刻，跑在本次因果运行的输出上** | 提案级去重 vs 本次运行最终地图 | **1,159** | **42.42/38.42/19.07** |
| v9 的 M1-only（无 M2） | 同上 | 1,159 | 39.04/35.11/16.94 |

**修正后的因果账本（本次实时运行为底座）**：
```
native base（本机在线跑出）     35.04 / 31.46 / 15.70
+ M1（v9 语义，场景末终稿）      39.04 / 35.11 / 16.94   (+4.00/+3.65/+1.24)
+ M2（场景末支持度，α=0.6）      42.42 / 38.42 / 19.07   (+3.38/+3.31/+2.13)
                                vs 论文 +13.21/+13.78/+11.03
```

结论修正：
1. **在线因果数字 = 42.42/38.42/19.07**（v9 语义：receipt 流内维护、birth 场景末定稿——与所有在线 3D 检测工作的"末帧地图评测"约定一致）。M1 的真实"因果代价"仅 −0.19（来源漂移：本机运行 vs sealed 输出 + 事件源差异），不是 −1.67。
2. v2 的 41.28 保留为"每时刻输出均有效"的强语义参照（birth 流内即入图）。
3. 前一 Addendum 的"不可化简的未来信息"论断**撤回**；v3–v7 的失败重定性为"对 map-so-far 去重必死"这一独立发现（仍然成立：流内瞬态框不能当去重目标，去重必须延迟到定稿）。
4. 语义要点：v9 的去重目标是**场景末的最终地图**——对在线系统而言这是"当前状态"，因果合法；v3 用"当时的中间地图"反而错。教训：因果性约束的是"数据时间"，不是"处理时刻的地图版本"。

### M4 首例（α 自校准）负结果
对照 fixed α=0.6 精确复现 41.28（重构无误）；adaptive（α=clip(2·(P90−P50), 0.2, 0.9)，先验固定）= **39.80/35.77/17.44（−1.48）**。死因：支持度分布顶部堆积，P90−P50 中位仅 ~0.11 → 中位 α 压到 0.23，而固定 α 剂量曲线单调偏好高 α。结论：**该分离度统计量不度量"信号可信度"**——M4 需换统计量（候选：支持度的双峰分离度/众数间距、或仅对低支持带自适应），留待留出复验后。产物：results/m4_fixed06、m4_adaptive；third_party/WeDetect/m4_alpha.py（含 100 场景支持度缓存 results/m4_alpha_supports.pkl）。

### 稳定性评测轴（D）：粒度受限负结果
kfmap 日志中地图框几何跨关键帧几乎不变（各 GT 桶中位漂移 0.0mm）——日志记录的是持久化地图快照，不含逐次融合精修。TP 漂移（p90 4.7mm）> FAR（0.8mm）的反直觉小发现：真物体被持续精修、幻觉框从不动。真正的稳定性轴需在融合更新点加细日志重跑（留作后续）；免标签判别检验失败（30% 最稳 track 的 TP 率 11.7% vs 基率 14.4%）。
